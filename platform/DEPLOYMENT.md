# Deployment

The deployment guide is the [README](../README.md#deployment). This branch deploys a fully private, keyless stack (Flex Consumption Function, private endpoints, shared-key access disabled, Azure Monitor Private Link Scope); the earlier static-website and Consumption-plan instructions no longer apply.

## Layout

```
platform/
├─ main.bicep                       # RG scope: workspace, App Insights, AMPLS, VNet, private endpoints, storage, Flex Function, workbook
├─ activity-export.bicep            # subscription scope: Activity Log -> workspace, Reader for the report identity
├─ policy-resource-health.bicep     # optional management-group policy that enrolls subscriptions automatically
├─ inject-queries.ps1               # service catalog and workbook query generator
├─ workbook-compute-sla.json        # generated by inject-queries.ps1 (do not edit by hand)
├─ queries.kql                      # raw KQL, workbook-independent
├─ Test-SlaPlatform.ps1             # post-deployment validation (run from a host on the VNet)
└─ function/
   ├─ host.json
   └─ GenerateSlaReport/
      ├─ function.json              # 0 0 6 1 * *  (1st of month, 06:00 UTC)
      └─ run.ps1
```

## Granting access

| Consumer | Roles | Where |
| --- | --- | --- |
| Workbook | `Reader`, `Log Analytics Reader`, `Workbook Reader` | The resource group holding the workbook and workspace |
| Monthly report | `Storage Blob Data Reader` | The storage account (or the `reports` container) |

Both surfaces require a network path to the private endpoints (corporate VPN/ExpressRoute with resolvable private DNS).

## Cost guardrails

- Set a daily ingestion cap on the workspace (**Settings → Daily Cap**).
- Create a Log Search alert on the per-resource KQL with `| where AvailabilityPct < 99.9` for SLA breaches.
- The Function runs once a month on Flex Consumption and scales to zero; the private endpoints (storage blob/queue/table, Function, AMPLS) are the main fixed cost.
